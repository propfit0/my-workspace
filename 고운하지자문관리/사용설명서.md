# 고운하지흉부외과의원 보험 자문 현황 관리 — 사용설명서

## 1. 처음 한 번만: 설치
1. 이 폴더(`고운하지자문관리`)에서 **`설치.bat`을 더블클릭**합니다. (인터넷 필요, 몇 분 걸립니다)
   - "파이썬이 설치되어 있지 않습니다"라고 나오면 python.org에서 Python 3.12를 설치한 뒤 다시 실행하세요.
2. "설치가 끝났습니다"가 나오면 창을 닫습니다.

## 2. 연습해 보기 (가상 데이터)
실제 자료를 넣기 전에 **`테스트실행.bat`** 을 더블클릭해 연습해 보세요.
- 가상의 환자(테스트환자01…)가 들어 있는 **연습용 데이터**로 열립니다. 비밀번호는 `test1234`입니다.
- 실제 데이터와는 완전히 분리된 `테스트데이터` 폴더를 사용하므로, 마음껏 입력·삭제해도 됩니다.

## 3. 실제 사용: 실행
**`고운하지자문관리.exe`(또는 `실행.bat`)를 더블클릭**하면 비밀번호 없이 바로 메인 화면이 열립니다.
- 데이터는 이 PC의 **Windows 계정으로 암호화**되어 저장됩니다. 파일을 다른 PC나 다른 Windows 계정으로 가져가면 열 수 없습니다.
- 대신 **이 PC에 로그인한 사람은 누구나 프로그램을 열 수 있습니다.** 자리를 비울 때는 Windows 화면 잠금(**Win + L**)을 사용하세요.
- 처음 실행하면 복구 키 보관 안내가 한 번 나옵니다. **복구 키**는 PC를 바꾸거나 Windows를 다시 설치한 뒤 데이터·백업을 열 때 필요합니다. `[설정] → 복구 키 보기 / 저장`에서 언제든 확인하고 USB 등에 저장해 두세요.

### 이전 버전(비밀번호 방식) 데이터가 있는 경우
새 버전을 처음 실행할 때 **기존 비밀번호를 한 번만** 입력하라는 창이 나옵니다(복구 키도 가능).
1. 전환 전 원본이 `%APPDATA%\고운하지자문\전환전_백업` 폴더에 그대로 보관됩니다.
2. 전환 후 내용이 원본과 같은지 자동 검증하고, 문제가 있으면 원본을 그대로 유지합니다.
3. 이후로는 비밀번호 없이 열립니다. 이전 버전이 만든 백업 파일(.gjbak)도 예전 비밀번호 또는 복구 키로 복원할 수 있습니다.

## 4. 기본 사용법
| 하고 싶은 일 | 방법 |
|---|---|
| 새 사건 등록 | [＋ 신규 등록] → 7개 항목 입력 → [등록]. 모르는 항목은 비워 두어도 됩니다. 날짜는 "날짜 지정"을 체크한 뒤 달력에서 고릅니다. |
| 진행 내용 추가 | 목록의 행을 **더블클릭** → "새 진행 내용"에 적고 [기록 추가]. 기존 기록은 지워지지 않고 날짜·시간과 함께 쌓입니다. |
| 사건 종결 | 상세 창에서 **최종 처리결과**를 입력하고 [저장]. 입력하면 "처리 완료"로 분류됩니다. 진행 중에는 비워 두세요. |
| 검색 / 걸러보기 | 위쪽 검색창(환자명·보험회사), 전체/진행 중/처리 완료, 진행상황·처리결과 목록 |
| 기록 수정·삭제 | 상세 창에서 기록을 선택 → [수정]/[삭제]. 수정 전 내용은 [수정 이력 보기]에 남고, 삭제한 기록은 "삭제된 기록도 보기"에서 되살릴 수 있습니다. |
| 사건 삭제 | [선택 사건 삭제] → 휴지통으로 이동. [휴지통]에서 복원하거나 완전 삭제할 수 있습니다. |

- 같은 환자가 여러 보험회사에 청구했거나 여러 번 수술했다면, **사건을 각각 따로 등록**하세요. 사건마다 관리번호(예: 2026-0001)가 자동으로 붙습니다.
- 작성 중인 글은 몇 초마다 자동으로 임시 저장되어, 갑자기 종료돼도 다음에 다시 열면 복구됩니다.

## 5. 주간 보고서 (매주 일요일)
1. [주간 보고서]를 누르면 **이번 주 월~일**이 기본 기간으로 잡히고 미리보기가 나타납니다. 기간은 직접 바꿀 수 있습니다([지난 주] 버튼도 있습니다).
2. 미리보기에서 확인합니다.
   - 위쪽 요약: 전체/진행 중/처리 완료 건수, 이번 주 신규·변경·종결 건수, **지난 보고서 대비 증감**
   - 구분: 신규 등록 / 진행 내용 변경 / 처리 완료 / 진행 중(변경 없음 — 누락되지 않고 계속 표시)
   - "▸ 지난 보고 대비 변경"에 바뀐 항목이 표시됩니다.
3. 병원에 이름을 가리고 보내려면 **"환자명 마스킹"** 을 체크합니다(김○○). 비고 안에 적힌 환자 이름도 함께 가려집니다.
4. [엑셀로 저장] 또는 [PDF로 저장]을 누르면 보고서가 **확정 저장**(작성 당시 내용 보존)되고 파일이 만들어집니다. 만든 파일을 병원에 직접 전달하세요. (자동 발송은 없습니다.)
5. 나중에 [저장된 보고서 불러오기]에서 과거 보고서를 당시 내용 그대로 다시 보고 다시 저장할 수 있습니다.

> 엑셀·PDF 파일은 암호화되지 않습니다. 환자 정보가 들어 있으니 전달 후 불필요한 사본은 삭제하세요.

## 6. 백업 방법 (꼭 읽어 주세요)
- **자동 백업**: 프로그램을 **종료할 때마다** 자동으로 백업됩니다(최근 30개 보관). 위치: `[백업·복원] → 자동 백업 폴더 열기`
- **수동 백업**: `[백업·복원] → 지금 백업 파일 저장…` 으로 USB나 다른 PC 폴더에 저장하세요. **일주일에 한 번, 보고서 작성 후 USB에 백업**하시길 권합니다.
- 백업 파일도 암호화되어 있어, 분실해도 복구 키 없이는 다른 PC에서 열 수 없습니다.
- 컴퓨터가 고장 나도 USB 백업 + **복구 키**가 있으면 다른 컴퓨터에서 복원할 수 있습니다.

## 7. 복원 방법
1. `[백업·복원] → 백업 파일에서 복원…` → 백업 파일 선택
2. 같은 PC의 백업은 바로 열립니다. 다른 PC에서 만든 백업이면 **복구 키**(이전 버전 백업은 예전 비밀번호도 가능)를 입력
3. **미리보기**(백업 시점, 건수)와 현재 데이터를 비교해 확인
4. "복원"이라고 직접 입력해야 진행됩니다
- 복원 직전의 현재 데이터는 자동으로 따로 보관(`자동 백업 폴더`의 `복원전_…` 파일)되므로, 잘못 복원해도 같은 방법으로 되돌릴 수 있습니다.
- 복원 후에도 지금 사용 중인 복구 키는 그대로입니다.

## 8. 데이터가 저장되는 곳
**`%APPDATA%\고운하지자문`** 폴더입니다. (탐색기 주소창에 `%APPDATA%\고운하지자문`을 입력하면 열립니다.)
프로그램 폴더와 분리되어 있어, 프로그램을 다시 설치하거나 옮겨도 데이터는 그대로 남습니다.
- `자문현황.gjdb` : 암호화된 데이터 파일 (`.prev`는 직전 저장본)
- `자동백업\` : 자동 백업 파일
- `오류기록.txt` : 오류가 났을 때만 생기는 기록(환자 정보는 들어가지 않음)

외부 서버로 전송되는 기능은 **전혀 없습니다**(인터넷 없이 동작).

## 9. 자주 묻는 질문
- **복구 키를 잃어버렸어요** → 같은 PC·같은 Windows 계정에서는 계속 열립니다. 지금 바로 `[설정] → 복구 키 보기 / 저장`에서 다시 저장해 두세요. (이전 버전에서 쓰던 복구 키는 프로그램이 문자열을 알지 못하므로, 그때 보관한 것을 그대로 사용하세요.)
- **"복구 키 필요" 창이 떠요** → 데이터 파일이 다른 PC·다른 Windows 계정에서 만들어진 것입니다. 복구 키를 입력하면 열리고, 이후 이 PC에서는 입력 없이 열립니다.
- **"이미 실행 중입니다"가 나와요** → 이미 열려 있는 창을 확인하세요. 두 개를 동시에 열면 데이터가 꼬일 수 있어 막아 둔 것입니다.
- **프로그램이 갑자기 꺼졌어요** → 다시 실행하세요. 저장은 입력할 때마다 즉시 이루어지고, 쓰던 글은 임시 저장됩니다.
- **데이터 파일이 손상됐다고 나와요** → 자동으로 직전 저장본으로 열어 줍니다. 그래도 안 되면 `[백업·복원]`으로 최근 백업을 복원하세요.
- **PC를 바꾸고 싶어요** → 새 PC에서 exe 실행 → `[백업·복원] → 백업 파일에서 복원…` → USB 백업 선택 → 복구 키 입력.
